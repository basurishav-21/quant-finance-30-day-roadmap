# Quant Finance 30-Day Roadmap

Notebooks and code from a self-directed 30-day program covering math 
foundations and their Python implementation, building toward applied 
quant finance projects using real market data.

**Math covered:** algebra, functions (notation, domain/range, 
composition, inverses), graphing and transformations, exponents/logs, 
trigonometry, limits, derivatives, single- and multivariable calculus, 
linear algebra (vectors, matrices, eigenvalues, SVD), and basic 
probability/statistics.

**Python:** NumPy, pandas, Matplotlib, SymPy, and CVXPY — used to 
implement and visualize each math concept as it's covered.

Notebooks are added incrementally as the program progresses; each day 
builds on the previous one.
